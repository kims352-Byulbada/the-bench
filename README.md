# The Bench

Professor Paul Carlos wouldn't say what good typography looks like — so this page lets you decide.
Type one line, search any of ~1,900 Google Fonts, then set its weight, size, tracking, case and alignment.
Hover over the headline and each word switches to a random typeface.

**Live:** https://kims352-byulbada.github.io/the-bench/

Spun off from Core 1: Interaction, Project 1B (an interview with Paul Carlos) · Built with HTML, CSS and JavaScript · Fall 2026
